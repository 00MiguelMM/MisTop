# Retrospectiva del proyecto

## Qué he aprendido

Durante esta práctica he aprendido a desarrollar una aplicación fullstack utilizando React, TypeScript, Tailwind CSS y una API conectada mediante Vercel.

También he aprendido:

- organización de proyectos grandes
- arquitectura frontend y backend
- creación de APIs REST
- despliegue en producción
- conexión entre frontend y backend
- gestión de errores y debugging
- documentación técnica del proyecto

## Qué fue más difícil

La parte más complicada fue la configuración del backend y el despliegue en Vercel.

Tuve varios problemas relacionados con:

- rutas de la API
- configuración de build
- instalación de dependencias
- conexión entre frontend y backend

Finalmente conseguí resolverlos simplificando la estructura de la API y revisando la configuración del proyecto.

## Qué mejoraría

Si continuara desarrollando MisTop, me gustaría añadir:

- autenticación de usuarios
- base de datos real
- sistema de favoritos
- imágenes para rankings
- edición completa de rankings
- animaciones y mejoras visuales

## Valoración final

Considero que esta práctica me ha ayudado mucho a entender cómo se desarrolla y despliega una aplicación fullstack real.

Además de la programación, también he aprendido la importancia de la organización, documentación y resolución de problemas durante el desarrollo.
